# Vermaak Website 

Build a modern, professional, responsive corporate website for Vermaak, an African creative-economy and digital-workforce company.

1. BRAND POSITIONING

Vermaak is a creative-economy and digital-workforce company that builds talent, markets, products, and systems for Africa's digital and creative economy.

Vermaak should be presented as an umbrella brand that develops and operates multiple products, platforms, services and ventures.

The main website should therefore function as the Vermaak ecosystem hub, with separate sections and links to individual Vermaak ventures.

Current ventures include:

Vermaak Academy — learning, skills development, masterclasses, professional training and digital workforce development.

Vermaak Consults — consulting services across digital transformation, data, research, project management, organisational development, creative economy and related areas.

EventSuite — an event technology platform providing digital tools and services for event organisers, attendees, creatives and event ecosystems.

Vermaak Events — events, experiences and creative productions.

Vermaak Creator House — a future platform/community for creators and digital talent.

Vermaak Galleries — a future creative and digital exhibition/gallery platform.

The architecture must allow additional Vermaak ventures to be added in the future without redesigning the whole website.

2. PRIMARY OBJECTIVE

The website should:

Clearly explain what Vermaak is.

Establish Vermaak as a credible African technology, creative-economy and digital-workforce company.

Showcase the different ventures under the Vermaak ecosystem.

Direct visitors to the appropriate venture.

Generate leads and enquiries.

Showcase projects, products, partnerships and impact.

Provide a strong platform for future expansion.

Be easy for a non-technical administrator to update.

The website should NOT feel like a simple personal portfolio.

It should feel like a modern African innovation company / venture studio / ecosystem company.

26. IMPORTANT DESIGN PRINCIPLE

Do not build all ventures as if they are equally mature.

Some are operational.
Some are developing.
Some are future ventures.

Therefore create a flexible status system:

ACTIVE
DEVELOPING
COMING SOON

This should automatically change how a venture appears on the website.

For example:

Vermaak Academy — ACTIVE

Vermaak Consults — ACTIVE

EventSuite — DEVELOPING

Creator House — COMING SOON

Vermaak Galleries — COMING SOON

Make these statuses editable from the CMS.

27. FUTURE-PROOFING

The most important requirement is that Vermaak should be able to become an ecosystem of multiple companies, platforms and products.

Do NOT structure the website around only the current six ventures.

Instead, create a dynamic:

Ventures Collection

where a new venture can be created from the admin dashboard and automatically appears on the Ecosystem page.

For example, in the future Vermaak could add:

Vermaak AI
Vermaak Studios
Vermaak Media
Vermaak Labs
Vermaak Marketplace
or other ventures.

The website should accommodate these without requiring major redevelopment.

28. FINAL DESIGN FEEL

The final product should feel like:

A modern African innovation company + creative ecosystem + digital venture platform.

It should be sophisticated enough to present Vermaak to:

Investors

Development partners

Governments

Corporates

NGOs

Universities

Creative professionals

Technology partners

Young professionals

Entrepreneurs

Do not make the website feel like a freelancer portfolio.

Do not overload the homepage with text.

Prioritise visual storytelling, strong typography, clear navigation, high-quality imagery and simple calls to action.

Build the first version with realistic placeholder content where information is not yet available, but make every placeholder editable through the CMS.

Ensure the website is fully responsive, accessible, fast-loading and production-ready.
